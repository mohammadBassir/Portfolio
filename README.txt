PAYENDA PORTFOLIO
=================

HOW TO RUN
1. Extract the ZIP file.
2. Open the payenda_portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

FILES
- index.html       Main portfolio page
- style.css        Responsive styling
- assets/hero-banner.png  Your supplied portfolio image

CUSTOMIZE
- Search in index.html for "your.email@example.com" and replace it with your email.
- Replace the sample project descriptions with your real projects and GitHub links.
- Update the skills and About Me text to match your experience.

The website uses plain HTML and CSS, with a small JavaScript snippet for the mobile menu and current year.
